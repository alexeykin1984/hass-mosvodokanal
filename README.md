# Мосводоканал для Home Assistant

Интеграция с личным кабинетом **физлица** АО «Мосводоканал» — [onewind.mosvodokanal.ru](https://onewind.mosvodokanal.ru) (прямой договор с Мосводоканалом).

## Возможности
- Все договоры учётной записи, включая расторгнутые, — каждый отдельным устройством
  (владелец договора в поле «Модель», номер договора — «Серийный номер»).
  Передавать показания можно только по действующим.
- Владелец договора и карточка договора: дата, тип, проживающие, площадь, доставка квитанций.
- Тарифы водоснабжения и водоотведения, ₽/м³.
- Статус передачи показаний за текущий период и даты приёма.
- Баланс (аванс), задолженность, последний счёт.
- Принятые Мосводоканалом показания каждого счётчика и ближайшая дата поверки.
- Передача показаний: кнопки «Проверить показания» / «Передать показания» и служба `mosvodokanal.send_readings`
  (с `dry_run` и ответом). Показания берутся из выбранных вами датчиков HA, округляются вниз до целых м³.
  Перед отправкой проверяется: период приёма открыт, есть показания всех счётчиков договора, показания не меньше прошлых.
- Данные обновляются раз в 6 часов и сразу после передачи.

## Установка
HACS → три точки → *Пользовательские репозитории* → URL этого репозитория, категория *Интеграция* → установить → перезапустить HA.
Затем *Настройки → Устройства и службы → Добавить интеграцию → Мосводоканал*.

После добавления откройте *Настроить* у интеграции и выберите датчик для каждого счётчика (по заводскому номеру).

## Пример автоматизации: передать 25-го числа
```yaml
automation:
  - alias: Мосводоканал — передать показания
    triggers:
      - trigger: time
        at: "10:00:00"
    conditions:
      - condition: template
        value_template: "{{ now().day == 25 }}"
      - condition: state
        entity_id: sensor.mosvodokanal_90227871_readings
        state: pending
    actions:
      - action: mosvodokanal.send_readings
```

## Примечания
- Сайт не отдаёт промежуточный сертификат GlobalSign — он входит в интеграцию, проверка TLS не отключается.
- DNS mosvodokanal.ru не отвечает на IPv6-запросы, поэтому соединение только по IPv4.
- После трёх неудачных входов кабинет включает капчу — войдите один раз через браузер.
- Неофициальная интеграция, протокол восстановлен по веб-интерфейсу кабинета.
